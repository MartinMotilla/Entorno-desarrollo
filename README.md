Descripción

Este repositorio contiene el trabajo de la tarea “Reconocimiento de Elementos en el Desarrollo de un Programa Informático”.

El objetivo de la actividad es reconocer los elementos y herramientas que intervienen en el desarrollo de un programa informático, diferenciando el código fuente, el código objeto y el código ejecutable, además de clasificar los lenguajes de programación en función de su nivel de abstracción y de su paradigma.
