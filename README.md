# Reconocimiento de Elementos en el Desarrollo de un Programa Informático

## Descripción

Este proyecto corresponde a la tarea **"Reconocimiento de Elementos en el Desarrollo de un Programa Informático"**.

El objetivo es reconocer los elementos y herramientas que intervienen en el desarrollo de un programa informático, diferenciando:

- Código fuente.
- Código objeto.
- Código ejecutable.
- Fases por las que pasa un programa desde que se escribe hasta que se ejecuta.
- Lenguajes de programación según su nivel de abstracción.
- Paradigmas de programación imperativo y declarativo.

## Contenido

El proyecto se divide en dos partes:

### Parte 1: Análisis teórico de conceptos

Se explican:

1. Los conceptos de código fuente, código objeto y código ejecutable.
2. Las fases por las que pasa un programa:
   - Análisis léxico.
   - Análisis sintáctico.
   - Análisis semántico.
   - Generación de código.
   - Compilación y/o enlazado.
   - Ejecución.
3. La clasificación de los lenguajes de programación:
   - Nivel alto.
   - Nivel medio.
   - Nivel bajo.
   - Paradigma imperativo.
   - Paradigma declarativo.

### Parte 2: Actividad práctica y de análisis

Se identifican los paradigmas de cuatro fragmentos descritos en la actividad:

- Fragmento 1: suma de números de una lista.
- Fragmento 2: consulta de empleados mayores de 30 años.
- Fragmento 3: cálculo recursivo de un factorial.
- Fragmento 4: filtrado de productos con precios superiores a 10 dólares.

También se incluye una actividad cotidiana explicada mediante un enfoque imperativo y otro declarativo, junto con una comparación entre ambos.
