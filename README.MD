# Cruz de Guía Sevilla

Este repositorio contiene la documentación inicial y el planteamiento del proyecto "Cruz de Guía Sevilla", una aplicación móvil y web oficial desarrollada en colaboración con el Consejo General de Hermandades y Cofradías de Sevilla.

## Estructura del Proyecto

* **informe.md**: Contiene toda la documentación formal del proyecto, incluyendo los objetivos, el modelo de desarrollo (Espiral + Scrum), los perfiles de usuario basados en la Interacción Persona-Ordenador (HCI) y las listas detalladas de requisitos funcionales y no funcionales.

## Resumen del Sistema

La aplicación está diseñada para resolver los problemas de desinformación en la calle durante la Semana Santa de Sevilla. Centraliza horarios, historias de las hermandades, misiones y venta de recuerdos en un canal verificado. Su punto clave es el diseño arquitectónico y de software pensado específicamente para mitigar el riesgo de colapso del sistema y cambios de itinerario por lluvia.

## Tecnologías Propuestas

* **Panel Administrativo (Web):** HTML, CSS y JavaScript.
* **Aplicación Móvil:** Desarrollo multiplataforma (compatible con sistemas Android e iOS).
